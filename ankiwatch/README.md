# AnkiWatch (cloze edition)

Review your AnkiDroid collection on a Wear OS watch (built for a Galaxy Watch 6), with
Enhanced Cloze cards laid out properly on the watch instead of as stripped template text.

Based on [AnkiWatch](https://github.com/OleksandrShabaldas/AnkiWatch) by Oleksandr Shabaldas
(MIT, commit `80d78a3`). Install guide and full notes: work in progress on this branch.
